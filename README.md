\# AI Network Assistant



AI Network Assistant is a web-based application that uses artificial intelligence to help users with computer networking.



The application provides explanations, troubleshooting assistance and network commands through a simple web interface.



\## Features



\### 💡 Ask AI

Ask questions about computer networking and receive clear explanations.



Example:

\- What is TCP?

\- What is DNS?

\- How does DHCP work?



\### 🔧 Network Troubleshooter

Describe a network problem and receive step-by-step troubleshooting guidance.



The assistant can suggest possible causes and useful commands such as:

\- `ping`

\- `ipconfig`

\- `tracert`

\- `nslookup`

\- Linux networking commands



\### ⌨️ Network Command Generator

Describe what you want to check and the AI generates useful networking commands.



Commands can be provided for:

\- Windows

\- Linux

\- Cisco IOS
